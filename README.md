# 🃏 Teen-Patti-Game-Using-ML
A Crazy Teen Patti card game built with machine learning for intelligent gameplay and a sleek user interface for an immersive gaming experience. This project combines the excitement of card games with the power of artificial intelligence. The game is designed to provide a realistic and engaging experience for players.

* Intelligent gameplay using machine learning algorithms
* Sleek user interface for an immersive gaming experience
* Realistic card game simulation

## How to Run Locally 🚀
1. Clone the repository using `git clone https://github.com/your-username/Teen-Patti-Game-Using-ML.git`
2. Install the required dependencies using `pip install -r requirements.txt`
3. Navigate to the project directory using `cd Teen-Patti-Game-Using-ML`
4. Run the game using `python run.py`
5. Follow the in-game instructions to play the game
